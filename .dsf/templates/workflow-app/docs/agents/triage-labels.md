# Triage labels

| Role in mattpocock/skills | In this repo | Meaning |
| --- | --- | --- |
| `needs-triage` | `status:todo` without a `type:*` | Not evaluated yet |
| `needs-info` | `status:blocked` | Waiting for more information |
| `ready-for-agent` | `status:ready` | Fully specified, an agent can take it |
| `ready-for-human` | `status:needs-human` | Needs a human decision or action |
| `wontfix` | closed with a reason | Will not be done |
